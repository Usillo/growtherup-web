# growtherup-web
Rediseño de growtherup.agency (GoHighLevel) mediante CSS/JS externo.

Pegar en GHL → Sites → Settings → Tracking Code → Head:

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/Usillo/growtherup-web@main/growtherup.css">
<script src="https://cdn.jsdelivr.net/gh/Usillo/growtherup-web@main/growtherup.js" defer></script>
```

Preview local: `python3 preview.py` → http://localhost:8765
